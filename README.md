# عين التاجر — Ain Al-Tajir 🛒📱

نظام متكامل لإدارة المتاجر والفروع مخصص لأصحاب المتاجر في السوق السعودي والأسواق العربية. يجمع التطبيق بين إدارة المخزون، والمبيعات، والمشتريات، والموردين، والفروع، والتحويلات الداخلية، والجرد، وإعادة التزويد، والتقارير، والاشتراكات.

---

## 🌟 المميزات الرئيسية

- **واجهة عربية أولًا مع دعم RTL والإنجليزية:** تجربة استخدام سهلة وسلسة للتجار في المملكة والخليج.
- **لوحة مؤشرات تفاعلية (Dashboard):** متابعة المبيعات الحية، الأرباح، المنتجات الأكثر مبيعاً، والمنتجات منخفضة المخزون.
- **إدارة المخزون والفروع المتعددة:** متابعة المخزون في كل فرع، وتعيين مديري الفروع بصلاحيات استلام واعتماد منفصلة.
- **حركات التحويل بين الفروع:** إنشاء ومتابعة واعتماد أو إلغاء تحويلات البضائع بين الفروع مع إشعارات فورية وسجل تدقيق غير قابل للتعديل.
- **إعادة التزويد الذكية والمشتريات:** اقتراح كميات إعادة الطلب آلياً عند انخفاض المخزون عن الحد الأدنى.
- **تسجيل استلام البضائع وفروقات التوريد:** مطابقة البضاعة المستلمة فعلياً مع أوامر الشراء، مع تصدير تقارير الفروقات بصيغتي **PDF** و **Excel (XLSX)**.
- **استكشاف ومقارنة الأسعار (Price Scout):** بحث ومقارنة أسعار السوق وحساب هوامش الربح بدقة.
- **فترة تجريبية مجانية 7 أيام:** تجربة حقيقية بكامل الصلاحيات بمجرد تسجيل المتجر، مع انتقال سلس لنظام الاشتراكات (100 ر.س شهرياً).
- **جاهزية الدفع الإلكتروني:** تكامل مع Stripe للاشتراكات والفوترة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend / Mobile:** Expo SDK 54, React Native 0.81, React 19, Expo Router, NativeWind (Tailwind CSS v3).
- **Backend / API:** Node.js, Express, tRPC v11 (Type-safe APIs), TypeScript.
- **Database & ORM:** Drizzle ORM, MySQL / TiDB Cloud.
- **Testing & Tools:** Vitest (105+ اختبار وحدة), Prettier, ESLint.
- **Build & CI/CD:** GitHub Actions (بناء تلقائي للـ APK), Expo Application Services (EAS).

## 🚀 التشغيل المحلي (Local Development)

### المتطلبات الأساسية
- Node.js (v20 أو أحدث)
- مدير الحزم `pnpm` (أو `npm`)

### خطوات التشغيل
1. تثبيت الحزم:
   ```bash
   pnpm install
   ```

2. إعداد ملف البيئة:
   ```bash
   cp .env.example .env
   # قم بتعديل قيم .env ببيانات الاتصال الخاصة بك
   ```

3. تشغيل الخادم والواجهة معاً:
   ```bash
   pnpm dev
   ```

4. أوامر التحقق والاختبار:
   ```bash
   pnpm check     # فحص توافق أنواع TypeScript
   pnpm test      # تشغيل اختبارات الوحدة (26 ملف اختبار)
   pnpm build     # بناء خادم الإنتاج
   ```

## 📱 تصدير وتحميل ملف APK (Android)

يوفر المشروع طريقتين لتصدير ملف APK:

### الطريقة الأولى: عبر GitHub Actions (مجاناً وبدون أي متطلبات على جهازك) ⭐ مستحسن
1. ارفع المشروع إلى مستودعك على GitHub.
2. انتقل إلى تبويب **Actions** في GitHub.
3. اختر سير العمل **Build Android APK**.
4. اضغط على **Run workflow**.
5. بعد انتهاء البناء (خلال 5-10 دقائق)، ستجد ملف `ain-al-tajir-app-apk.zip` متاحاً للتحميل مباشرة ضمن **Artifacts**.
6. فك الضغط وثبّت ملف الـ `.apk` على هاتفك الأندرويد.

### الطريقة الثانية: عبر سحابة Expo EAS Build
1. سجّل الدخول إلى حساب Expo:
   ```bash
   npx eas login
   ```
2. ابنِ نسخة الـ APK:
   ```bash
   pnpm build:apk
   # أو
   npx eas build --platform android --profile preview
   ```
3. سيعطيك الأمر رابطاً ورمز QR لتحميل وتثبيت الـ APK مباشرة.
